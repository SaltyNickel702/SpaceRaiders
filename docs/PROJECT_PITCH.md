For the TSA Video Game Design Competition<br>

### Purpose
Entry for the TSA game development competition

### First Version
One playable level with one ability

### Brainstorming
* Players progress through discrete levels
* Each level completed rewards experience
* Experience levels up the player, allowing them to unlock more abilities from a skill tree
* Levels and puzzles are built using an isometric camera and different perspectives to solve puzzles
* The player will have access to multiple levels at once, it is up to them to decide which one to attempt
* The player will always be able to leave a level and come back later
* There is no guarantee that a level will be completable with the player's current loadout
